# marimo — AI実装 / 業務自動化

生成AIを「デモ」ではなく「毎日動く実務の仕組み」にすることを専門にしています。
Claude Code を核に、要件整理から実装・検証・運用までを一気通貫で。

## 何をしている人か

- **AIハーネス設計**: CLAUDE.mdルール体系・スキル・役割特化エージェント・機械検証で、AIコーディングを「誰がやっても同じ品質」に → [claude-harness-template](https://github.com/mosumoss/claude-harness-template)
- **評価駆動のAI開発**: RAGをLLM-as-Judgeで数値改善（correctness 0.597→0.718）、引用根拠検証で幻覚ゼロ設計 → [jiko-coach](https://github.com/mosumoss/jiko-coach)
- **実務の自動化**: 収集→LLM採点→通知のパイプラインを24時間運用 → [cw-scout](https://github.com/mosumoss/cw-scout)
- **TDDでのフルスタック実装**: FastAPI × SvelteKit、テスト239件 → [line-pill-v2](https://github.com/mosumoss/line-pill-v2)

## Stack

Claude Code / Claude API · Python / FastAPI · TypeScript / Next.js · RAG (ChromaDB / sqlite-vec) · n8n / GAS · Docker · Playwright
